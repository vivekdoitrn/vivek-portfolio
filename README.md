## Run Locally

**Prerequisite:** Node.js 20.19+ or 22.12+.

1. Clone this repository.

2. Open the project directory in your terminal.

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Create a production build:

   ```bash
   npm run build
   ```
